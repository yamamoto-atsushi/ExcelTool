# Apple UI/UX準拠の改善点

## 現在の実装状況

### ✅ 準拠している点
1. **カラーパレット**: Apple Blue (#007AFF)、適切なグレースケール
2. **スペーシング**: 一貫したスペーシングシステム
3. **タイポグラフィ**: 明確なフォント階層
4. **ボタンホバー効果**: activebackgroundでホバー時の色変更

### ❌ 改善が必要な点

#### 1. ボタンの角丸
- **現状**: 角が直角
- **Apple標準**: 丸みを帯びた角（約8-12px）
- **制約**: Tkinterは直接角丸をサポートしていないが、視覚的な改善は可能

#### 2. エントリーフィールドの視覚的改善
- **現状**: フラットなボーダー
- **Apple標準**: より明確なフォーカス状態、軽い影
- **改善**: フォーカス時のボーダー色を強調

#### 3. カード/セクションの影
- **現状**: フラットな見た目
- **Apple標準**: 軽い影で深度感を出す
- **制約**: Tkinterは影を直接サポートしていない

#### 4. ボタンのパディング
- **現状**: 最小限のパディング
- **Apple標準**: 十分なタップ領域（最小44x44pt）
- **改善**: パディングを増やす

#### 5. セクション間の視覚的分離
- **現状**: スペーシングのみ
- **Apple標準**: より明確な分離（背景色の違い、軽いボーダー）

## 実装可能な改善

1. ✅ ボタンのパディングを増やす
2. ✅ エントリーフィールドのフォーカス時のボーダー色を強調
3. ✅ セクションの背景色とボーダーを改善
4. ✅ ボタンの視覚的階層を明確化
5. ⚠️ 角丸（Tkinterの制約により完全な実装は困難）
